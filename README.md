# StatsFree
Модуль для показа статистики игроков из Levels Ranks. Не имеет статистики в профиле и виджетов, только вывод в отдельной странице.  Полная версия - https://flute-cms.com/product/stats  ---  Module for showing player statistics from Levels Ranks. Does not have stats in profile and widgets, only output in a separate page.
